# Global policy (all agents)
<!-- Keep short. Longer rules belong in knowledge/policies-full/. -->
- Before non-trivial work: kb_search the task (add note_kind="decision" to check past decisions).
- After the task: kb_add what you learned or decided, with kind, the files it concerns, and links
  to related notes. Skip it if nothing non-obvious happened.
- If a note you find is wrong or outdated, check the current code, then kb_retire it with a reason.
- Never commit secrets, keys or credentials.
- Explain the plan before making large or irreversible changes.
